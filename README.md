# Video IA
Crea vídeos con IA a partir de un texto: guion, imágenes, voz en español y montaje animado con subtítulos. Sin límite de duración (más escenas = más largo). Servicios gratuitos de Pollinations, sin claves.

## Usar como web instalable
Sube la carpeta `www/` a GitHub Pages (o cualquier hosting HTTPS) y en el móvil: menú del navegador → "Instalar app".

## Obtener el APK
1. Sube todo este proyecto a un repositorio de GitHub.
2. Pestaña **Actions** → "Compilar APK" (se lanza solo al subir) → cuando termine, descarga `VideoIA-apk` (contiene `app-debug.apk`).
3. Instálalo en el móvil permitiendo "orígenes desconocidos".
